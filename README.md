## Project objective

Develop a machine-learning model that estimates the dataset's observed Steam game price using selected non-price features: genre, launch year, review count, and general review summary. Compare a baseline and several regression algorithms, evaluate the selected model using an untouched test set, then expose predictions through a Streamlit interface.

**Target definition and leakage control:** `price` is the target. The dataset also contains `discount` and `original_price`, but these are excluded from input features because they directly relate to price and may leak target information. The prediction is an estimate of the snapshot price in the source dataset, not a forecast of future prices or a live Steam quote.

## Quick start

Windows users can run `run_project.bat` to create the environment, install dependencies, download the dataset, train the model, and launch the app. The steps in the following section can also be run manually.

## Workflow

1. Download the raw CSV from the public Zenodo record.
2. Inspect column names, data types, duplicates, missing values, and price formats.
3. Clean the data and extract launch year.
4. Perform EDA in `notebooks/online_game_price_prediction.ipynb`.
5. Split data 80/20 using a fixed seed.
6. Compare Median Baseline, Ridge Regression, Decision Tree, Random Forest, and Extra Trees using five-fold cross-validation MAE on training data.
7. Select the model with the lowest mean CV MAE; evaluate that model once on the held-out test set.
8. Read evaluation metrics and comparison output from `reports/`.
9. Launch the Streamlit UI.

## Input features

| Feature | Meaning | Processing |
|---|---|---|
| `genres` | Genre or genre string from the source | Missing values become `Unknown`; one-hot encoding |
| `launch_year` | Year extracted from the release date | Invalid/missing years are imputed in the preprocessing pipeline |
| `reviews` | Number of reviews | Parsed to numeric; missing values become 0 in cleaning |
| `general_reviews` | Review summary/category from source | Missing values become `Unknown`; one-hot encoding |
| `price` | Observed price in euros | Target only, not an input |

## Output files generated after training

- `models/best_model.joblib` — selected fitted preprocessing/model pipeline
- `models/model_metadata.json` — options and training/test metadata required by the app
- `reports/model_comparison.csv` — five-fold validation MAE per model
- `reports/test_metrics.json` — final held-out metrics for the selected model
- `reports/test_predictions.csv` — actual/predicted test values

Model results are intentionally generated by the user's run and are not pre-filled with invented accuracy or error scores.

## Important limitations

- Dataset prices are a snapshot collected in March 2025 from the Spanish-language Steam web store; actual current prices vary by time and country.
- Predictions are associative estimates from a small public dataset; they are not guarantees of a game's market price.
- This is an academic prototype and must not be described as a live price checker.
